# Smart Expense Tracker

A simple web application to manage daily income and expenses.

## Features
- Add income and expense transactions
- Categorize transactions
- Calculate total income, expenses, and balance
- Delete transactions
- Save transaction data using browser localStorage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding your income and expenses.

## Project Purpose
This project was developed to practice front-end web development and JavaScript fundamentals.
